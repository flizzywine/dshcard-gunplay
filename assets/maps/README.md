# 本地地图素材

此目录的运行资源由外部游戏地图转换而来，未包含在 2026-11-03 的远程纪念存档中。本地 D 盘工作副本仍保留全部文件，不会因 Git 忽略规则而删除。

- `cracked.glb`、`cracked-collision.bin`、`cracked.json`、`cracked-radar.svg`：本机《三角洲行动》烬区灰盒，按项目 README 中的 `build:cracked` 流程准备。
- `dust2.json`、`dust2-radar.svg`：来源、转换与重建见 [DUST2-SOURCE.md](DUST2-SOURCE.md)。
- `karkand.json`、`karkand-radar.svg`：来源、转换与重建见 [KARKAND-SOURCE.md](KARKAND-SOURCE.md)。

地图缺失时，对应的加载及地图测试无法运行；代码存档不把下载可用视为素材的再分发许可。
