# 本地三角洲武器简化版

本地开发版的四个固定槽位：1 腾龙突击步枪、2 M870 霰弹枪、3 AWM 狙击步枪、4 AT4 火箭筒。AT4 直接替换原火箭筒槽，不受兵种限制。

模型和基础颜色贴图来自本机《三角洲行动》。内部资源命名分别为 QBZ191、M870、AW 和 AT4。由 22 个第一人称部件按原骨骼与 socket 装配，保留原尺度，转换厘米为米；保留机匣、枪管、护木、弹匣、枪托及瞄具。生成物包含约 2.9 MB 几何与最高 1024 像素的基础颜色贴图，没有载入原作复杂材质、音效或动画。

当前动作使用本项目的简化换弹与手臂动画：腾龙/AWM 弹匣更换，M870 逐发装填和护木泵动，AWM 枪栓后拉。AT4 的 R 换弹动作丢下旧筒、取出新筒并重新上肩，4.1 秒完成后才消耗备用弹药和恢复 1 发装填；切枪或复活会取消并重置模型。AT4 右键进入独立 2.4 倍瞄具，AWM 使用现有高倍镜遮罩。

腾龙胸部伤害 34→26，75→220 米衰减，普通 100 血目标需要约 3–4 发胸部命中；AWM 胸部 115→105，霰弹枪仍是 9 颗弹丸的近距离武器。腾龙/AWM 判定射程分别为 650/900 米，避免在烬区遇到旧 400 米硬上限。HUD 将实际命中伤害和敌人剩余生命单独显示，压制得分不代表伤害。弹道、伤害和弹药为本游戏的平衡数据，不声称复现原作数值。武器内部旧 ID 为存档兼容保留。

来源索引：`weapons.json` 的每个 part.source 指向原始资源路径。本地解析工具与中间资源保存在 `D:/Workspace/deltaforce-map-extract/`。这是本地开发素材，原作资产版权属于原权利人，未纳入已发布人物卡；旧 Unvanquished 预览及许可文件仍保留。

重建：

```powershell
node scripts/build-delta-weapons.mjs D:/Workspace/deltaforce-map-extract/exports/weapons
```

运行本地服务器后：`node test/delta-weapons-browser.mjs` 检查四槽模型、开火、换弹、泵动、拉栓并保存腰射/瞄准/换弹截图。`node test/launcher-ads-browser.mjs` 检查 AT4 在三种宽高比、三种开镜进度下的中央视野；`node test/arsenal-browser.mjs` 检查切换、死亡补弹和贴墙火箭碰撞。
