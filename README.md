# Pixel Gunplay · 像素突击 V2

单人、电脑键鼠、像素风 3D 游戏原型：与 9 名队友对抗 20 名防守人机，依次突破五个据点。无联网对战、账号、付费或运行时外部 CDN 请求。

## 本地启动

安装 **Node.js 24 或更新版本**，克隆或下载本仓库后，在项目目录运行：

```sh
npm start
```

浏览器打开 **http://127.0.0.1:8080**。不需要 `npm install`，不需要构建。停止服务按 Ctrl+C。默认只监听本机；端口占用时可设置 `PORT` 环境变量。

也可以安装 Python 3 后运行：

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

不要直接双击 `dist/index.html`（`file://` 不支持模块加载）。需电脑浏览器支持 **WebGL2** 并开启硬件加速；点击画面后锁定鼠标，Esc 释放。

## 操作速查

- WASD 移动；Shift 冲刺；空格跳跃；C 蹲伏/滑铲。
- 左键射击、右键瞄准；R 换弹；1–4 或滚轮切换四种武器。
- Z 突击位移；X 工程燃烧弹；F 支援补给；Q 侦察脉冲。
- B 召唤机甲；靠近后 E 驾驶/退出。
- 5 跟随、6 进攻、7 守点、8 集火；T 切换三人/全队。
- Tab 战绩；Esc 暂停。

详细规则、地图来源和现有限制见 [GAMEPLAY.md](GAMEPLAY.md)。

## 目录、依赖与测试

- `dist/`：可直接运行的完整静态源码、样式和本地 Three.js **r169**（含所需插件）；无需外部资源下载。
- `tests/`：安全的无浏览器逻辑测试；`scripts/`：本地静态服务与测试入口。
- `upstream-package.json`：上游元数据，**不是本项目的安装入口**。

```sh
npm test
```

测试使用 Node.js 24，覆盖菜单、战斗、技能、机甲、导航、碰撞、占点与整场模拟。Node 的实验性 loader 警告不代表失败。无 GPU 的云测试环境无法建立 WebGL 上下文，因此 **未完成真实 3D 画面、实战手感和 GPU 帧率验证**；模拟结果不等于 FPS 或难度保证。

## 当前导出验证结果（2026-11-02）

本地静态 HTTP、模块路径/MIME、菜单、战斗、技能、AI、地图导航、资源清理和无辅助整场模拟通过。完整 `npm test` 中，辅助控制器 `ASSISTED=1 SEED=2401` 的整场模拟出现失败：600 模拟秒结束时占领 4/5 点（预期 5/5）。一次不改代码的同种子复跑通过（119.35 模拟秒、5/5 点、85 次玩家击杀），说明此测试目前不能仅靠该种子稳定复现，具体原因尚未定位。因此不能声称全套测试稳定通过，也不能保证自动控制器总能通关；为保留现有玩法，此次导出没有修改游戏逻辑或放宽断言。历史模拟数据见 GAMEPLAY.md，不是本次全套通过的证明。
